# Bundled Noto typefaces

This directory contains the three fonts embedded into the ALAS desktop binary:

- `NotoSans-Variable.ttf`: proportional application text.
- `NotoSansMono-Variable.ttf`: console, paths, and numerical text.
- `NotoSansMath-Regular.ttf`: fallback for engineering notation.

They were obtained from the Google Fonts repository revision
`e44c4b011a820c2cbe2fd2cfa8052037d7edb571`:

- `ofl/notosans/NotoSans[wdth,wght].ttf`
- `ofl/notosansmono/NotoSansMono[wdth,wght].ttf`
- `ofl/notosansmath/NotoSansMath-Regular.ttf`
