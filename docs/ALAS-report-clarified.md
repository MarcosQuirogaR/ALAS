Retain labels, values, units, validation messages, and the explicit exceptions requested below: visible findings, sandbox estimate labels, walkthrough content, and aerodynamic formulas. **Files:** [alas-gui/theme.rs](C:/Proyectos/ALAS/crates/alas-gui/src/theme.rs), [alas-gui/views/form_page.rs](C:/Proyectos/ALAS/crates/alas-gui/src/views/form_page.rs), [alas-gui/views/form_page_sections.rs](C:/Proyectos/ALAS/crates/alas-gui/src/views/form_page_sections.rs).

### 1.1. Feature: Clean-Sheet Sandbox Mode

#### 1.1.1. Trigger and entry conditions

On first entry, Clean sheet design opens a sandbox initialized from AVE. Later entries resume the last sandbox/custom design unless New from AVE is selected. Create a separate editable sandbox case while preserving any previously active case. On leaving sandbox, explicitly ask whether to discard the sandbox geometry or promote it to the active design; cancellation should leave the sandbox open.
